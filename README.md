InfraWatch Cloud

Python-Based Infrastructure Monitoring | AWS | Cloud Engineering | DevOps

InfraWatch Cloud is an infrastructure monitoring project designed to collect system performance metrics, identify resource utilization issues, and demonstrate practical skills in cloud computing, Linux administration, and DevOps.

Features

- Real-time CPU usage monitoring
- RAM utilization monitoring
- Disk usage monitoring
- Resource threshold alerts (80%)
- Windows and Linux compatibility

Tech Stack

- Python
- psutil
- Git & GitHub
- AWS (planned)
- Docker (planned)
- GitHub Actions (planned)

Getting Started

1. Install dependencies

"py -m pip install -r requirements.txt"

2. Run the application

"py monitor.py"

On Linux, use "python3" instead of "py".
